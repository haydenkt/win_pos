Before your first site visit

  1. Open this page over trusted HTTPS and connect while online.
  2. Wait for “Offline app ready.” Add it to your home screen using your browser menu.
  3. Reopen the installed app, connect, then test opening it in airplane mode.
  4. Save each survey on the phone. Back at the factory, reconnect and use Sync for each draft.

Plain HTTP over a Wi-Fi IP cannot install the offline shell. Keep the tab open for a temporary test, and export backups. A trusted HTTPS setup is still needed for reliable phone use.
